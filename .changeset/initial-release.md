First release: a framework-free core that loads the goya24 messenger and controls it (`open`, `close`, `toggle`, `identify`, events for `ready`/`open`/`close`/`unread`/`error`), and thin wrappers for React and Next.js (`<Goya24 />`, `<Goya24Provider>`, `useGoya24()`), Vue 3 (`createGoya24()`, `useGoya24()`) and Nuxt 3 (`@goya24/nuxt` module with `runtimeConfig.public.goya24`).
